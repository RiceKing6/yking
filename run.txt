================================================================
  yking 运行说明（Windows / 环境已装好，直接看第二节即可）
================================================================

yking 是一个命令行 AI 编程助手，它被安装在名为「yking」的 conda
虚拟环境里（Python 3.12），源代码在 D:\yking。
你的本地 Python 环境没有被改动过。

----------------------------------------------------------------
一、三个前置事实（了解后就不会懵）
----------------------------------------------------------------

1) yking 不是双击运行的图形程序，它是一条终端（黑窗口）命令。
   打开终端的方法：按 Win 键 -> 输入 cmd -> 回车（推荐用 CMD）。

2) 每次使用前要先「激活」conda 环境，激活后才有 yking 这条命令：

       conda activate yking

3) yking 启动时所在的目录，就是它的「工作目录」：
   它读写文件、执行命令都默认发生在这个目录里。
   所以正确姿势是：先进到你想要它干活的项目文件夹，再启动 yking。

----------------------------------------------------------------
二、标准用法：三步启动（建议背下来）
----------------------------------------------------------------

第 1 步  打开 CMD，激活环境

       conda activate yking

       成功标志：命令行开头多出 (yking) 字样，比如：
       (yking) C:\Users\HASEE>

第 2 步  进入你想让 yking 干活的目录（以 D:\myproj 为例）

       cd /d D:\myproj

       （cd /d 是 CMD 的写法，可以跨盘符；同一盘符内直接 cd 也行）

第 3 步  启动

       yking

       看到下面这样的画面就是成功了：

       yking v0.1.0 — 命令行编码 Agent（ReAct + Tool Call）
       model=deepseek-chat  workspace=D:\myproj  输入 /help 查看帮助，/exit 退出

       you ❯     <- 在这里直接用中文打字提需求，按回车发送

退出方式：输入 /exit 回车，或直接按 Ctrl+C。

----------------------------------------------------------------
三、常用启动命令一览（都是先 conda activate yking 再执行）
----------------------------------------------------------------

  yking                      交互式对话（最常用）
  yking -p "问题"             问一句就自动退出，不进入交互界面
  yking --plan -p "任务"      单次「先规划成任务列表再逐步执行」模式
  yking --check              检查配置（API Key、模型、工作目录）
  yking --version            查看版本

其他可选参数（可以组合使用）：

  -w D:\some\project         指定工作目录（等价于先 cd 过去）
  --no-stream                关闭流式输出（默认是一边生成一边显示）
  --parallel 3               Plan 模式下并行执行无依赖的任务（默认 1 = 串行）
  --multi                    单次模式（-p）改用 Multi-Agent 三角色协作
  --auto-approve             执行命令/确认计划时不再逐个询问（自动化用）
  --model deepseek-chat      临时换个模型
  --help                     查看全部参数说明

不想每次激活环境？也可以不激活直接跑（--no-capture-output 必须加，
否则输出不实时）：

  conda run --no-capture-output -n yking yking

----------------------------------------------------------------
四、进入 yking 之后（对话界面里能用的斜杠命令）
----------------------------------------------------------------

  /plan 需求        先让 AI 把需求拆解成带依赖关系的任务计划（DAG），
                    你按 Y 确认后它再一个任务一个任务地执行（适合复杂任务）
  /multi 需求       Multi-Agent 模式：Planner 拆解 -> Worker 执行 ->
                    Reviewer 独立验收把关，不通过就打回重做（质量要求高时用）
  /remember 内容    写入长期记忆（跨会话保留，如：/remember 这个项目用 pytest）
  /memory           查看长期记忆
  /forget 编号      删除某条长期记忆（编号来自 /memory）
  /clear            清空当前对话历史（长期记忆保留）
  /model            查看当前用的模型和接口地址
  /help             查看帮助
  /exit             退出

不加斜杠、直接打字就是正常对话或下达任务，例如：

  you ❯ 帮我写一个 python 脚本，把当前目录所有 .txt 合并成一个文件
  you ❯ /plan 给这个项目补上单元测试

----------------------------------------------------------------
五、出问题了？按顺序排查
----------------------------------------------------------------

1) 提示「yking 不是内部或外部命令」
   -> 忘了 conda activate yking，或激活失败。重做第二节第 1 步。

2) 提示「未找到 API Key」
   -> 检查 D:\yking\.env 文件是否存在，里面是否有 YKING_API_KEY=... 这一行；
   -> 改完保存，重新运行 yking 即可，不用重启终端；
   -> 用 yking --check 验证，api_key 应显示成 sk-ce6****167e 这种脱敏样子。

3) conda activate 报错（PowerShell 常见，提示让你 conda init）
   -> 按提示执行一次 conda init powershell，然后关掉终端重新打开；
   -> 或者干脆改用 CMD（Win 键 -> cmd），CMD 一般直接就能激活。

4) 提示请求失败 / 连接错误
   -> 先检查网络（是否需要开代理）；
   -> 可以试试 yking --no-stream；
   -> 用 yking --check 确认 base_url 和 model 没有被改错。

5) yking 执行命令前问你「允许执行? [y/N]」
   -> 这是安全确认：看清命令内容后输 y 回车 = 允许，直接回车 = 拒绝；
   -> 不想被问就在启动时加 --auto-approve 参数。

----------------------------------------------------------------
六、两个常见疑问
----------------------------------------------------------------

1) 修改了 D:\yking 里的代码，需要重装吗？
   不需要。当初是用 pip install -e D:\yking「可编辑模式」装的，
   代码一改，下次运行 yking 自动就是新的。

2) 换个文件夹启动，API Key 还在吗？
   在。配置都放在 D:\yking\.env 里，无论你在哪个目录启动 yking
   都会读到这份配置，不用复制 .env 到别处。

----------------------------------------------------------------
七、万一环境丢了，从零重建（一般用不到，备查）
----------------------------------------------------------------

  conda create -n yking python=3.12 -y
  conda activate yking
  pip install -e D:\yking
  yking --check

（.env 配置文件已在 D:\yking 里，无需重建。）
